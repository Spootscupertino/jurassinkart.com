# The Living Past — Session Record, 2026-07-23

Plain-language log of everything we did today. (Recipe/spec live in `mj_recipe.md`,

## The headline
**The pipeline fundamentally changed today: Claude can now generate images in Midjourney
directly** (driving the in-app browser on your logged-in MJ session). For the whole life of
this project the generator could only *print* a prompt for you to paste by hand. That
bottleneck is gone for text-driven runs — and it reshapes how every future session works.

## What we accomplished

**1 · Proved direct MJ generation.** Claude sets the imagine bar, submits, and reads the grid
back live. We used it twice in real time to solve real problems (below). Reliable path:
`form_input` to set the prompt (typing is flaky in MJ's editor), send button to submit, poll.

**2 · Fixed the T. rex full-body crop.** Every generation was cropping to a hero head/chest.
Diagnosed the cause: high `--ow` on head-study refs + macro-detail words + no framing language,
all voting "portrait." Fix (same one that beat the epic-scale crop): **front-load the framing**,
drop the macro cues, angle the pose ~30° off front. Ran it live → **full body, clean.** Then
added a **roaring** `pose` override to CR01 → full-body roaring T. rex. You're remixing the
"face-on roaring" set now; it looks like the keeper.

**3 · Made the recipe type-aware.** Pressure-tested the fix on the weird organisms and found the
one-size framing *breaks* on non-theropods. Rebuilt `lp_organism_prompt.py` with four framing
modes — **figure / wing / macro / plate** — plus type-correct anatomy + surface language.
**Validated the wing mode live on Quetzalcoatlus**: full wingspan, wingtip to wingtip, no clip.

**4 · Redesigned the production pipeline around a key insight (yours): MJ is the storage.**
No downloading. Claude (or a cheap executor) fires prompts into your MJ library; you curate
natively (delete duds, keep good — and the "fails" become `--sref` reference fodder, feeding the
library flywheel); only the final keepers ever leave MJ. Selection moved *out* of the executor
loop, which collapses it to a near-free "prompt firehose."

**5 · Built the production infrastructure:**
- `tools/compose_organism.py` — drop an MJ isolate → knockout the grey background → size to true
  scale → stand it on the terrace with a contact shadow. Tested end-to-end (T. rex at 3510px =
  ⅓ poster width, dead on target).
- `tools/build_organism_pages.py` — generates all **32 QR landing pages** from `volume_v.json`
  (proper slugs, SEO/OG/JSON-LD, Law-#4 "pending sourced fill" placeholders, no invention).
- `tools/build_queue.py` → `build_queue.json` + `BUILD_QUEUE.md` — the 32-organism production
  board with sizes, draw-px, aspect, and a live status column.
- `BUILD_RUNBOOK.md` — the labor split: **Fable authors the spec + sits at judgment gates; a
  cheap Sonnet executor grinds; you curate + attach refs.** Usage economics baked in.
